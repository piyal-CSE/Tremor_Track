🌍 Tremor Track - Earthquake Monitoring System

Real-time earthquake monitoring application with interactive maps, historical data charts, and instant alerts.

🚀 Live Demo

[View Live App]("https://piyal-cse.github.io/Tremor_Track")

✨ Features

- 📊 Real-time earthquake data from USGS
- 🗺️ Interactive world map with earthquake markers
- 📈 Historical data charts and visualizations
- 🔔 Sound alerts for significant earthquakes
- 🌙 Dark mode support
- 📱 Responsive design for all devices
- 🔄 Auto-refresh every 60 seconds
- 📢 Social sharing capabilities

 🛠️ Technologies Used

- React 18
- Recharts (Data visualization)
- Lucide React (Icons)
- USGS Earthquake API
- CSS3 with custom styling

 🏃 Running Locally

1. Clone the repository:
\`\`\`bash
git clone https://github.com/YOUR_USERNAME/Tremor_Track.git
cd Tremor_Track
\`\`\`

2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Start the development server:
\`\`\`bash
npm start
\`\`\`

4. Open [http://localhost:3000](http://localhost:3000) in your browser

📦 Building for Production

\`\`\`bash
npm run build
\`\`\`

🚀 Deployment

\`\`\`bash
npm run deploy
\`\`\`
